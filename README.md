# AstrBot Fishing Rework

面向 AstrBot 的多人钓鱼与经济系统插件。本项目从现有可玩版本迁移而来，
使用独立 Git 历史维护，不再作为原仓库的 Fork。

[仓库](https://github.com/AlphaZero78/astrbot_plugin_fishing_rework) ·
[更新记录](CHANGELOG.md) · [贡献指南](CONTRIBUTING.md)

## 当前特性

- 钓鱼区域、稀有度分布、鱼塘容量、水族箱和鱼类图鉴
- 鱼竿、饰品、鱼饵、精炼、品质和装备锁定
- 系统商店、玩家市场、抽卡池和大宗商品交易所
- 偷鱼、电鱼、擦弹、命运之轮、骰宝和群红包
- 成就、称号、排行榜、税收和管理员命令
- 默认开启的 WebUI，可管理模板、区域、商店、卡池和运行配置
- 商店、玩家市场和大宗商品交易所支持图片面板展示
- 交易所行情图片内置最近 7 天价格趋势折线图
- 交易所支持持仓盈亏、行情推荐、风险评分和个人容量升级
- 多实例共享 SQLite 数据库及跨版本兼容迁移

## 主要变化

- 时运沙漏始终准确保存并预测下一次擦弹倍率。
- “数量、品质、稀有度、重量/基础售价、冷却”使用统一术语。
- 渔获价值倍率持久化到鱼塘、水族箱和市场，不再只存在于日志。
- 区域、鱼饵、鱼竿、饰品和卡池可通过期望值工具复现和校验。
- 同一星级内所有鱼等概率出现；6 星以上按每升一星权重减半的方式递减。
- 除 WebUI 自身参数外的插件运行配置可在 WebUI 修改。
- 道具的 `effect_type` 和 `effect_payload` 可在 WebUI 编辑并校验。
- WebUI 展示数值会清理浮点误差与无意义尾零，同时保留编辑时的原始精度。
- WebUI 交易所页可热更新基础价格、市场状态、波动参数和每日更新时间。
- 管理员可通过命令立即更新或按基础价格重置交易所行情。
- 新数据库可从零完成迁移、基础数据填充和区域鱼类映射。
- 每日所得税按固定 `12:00–12:00` 周期汇总应税盈利并超额累进结算，免征额为 `1000万`；转账免税，交易所仅计算已实现正利润。
- 管理员 `/全体奖励金币` 支持固定金额或按每位用户持有金币百分比发放，百分比结果向下取整。

## 安装

将仓库放入 AstrBot 插件目录：

```bash
git clone https://github.com/AlphaZero78/astrbot_plugin_fishing_rework.git
```

安装依赖：

```bash
pip install -r requirements.txt
```

重新加载插件或重启 AstrBot。首次启动会自动执行数据库迁移并填充基础数据。

> 运行时 `plugin_id` 暂保留为 `astrbot_plugin_fishing`，用于兼容既有配置和
> 数据目录。不要同时加载旧插件和本项目。

## 数据迁移

默认数据库位于 AstrBot 为插件分配的数据目录。也可以通过
`storage.shared_db_path` 指定已有 `fish.db` 的绝对路径。

迁移前应备份：

```text
fish.db
fish.db-shm
fish.db-wal
```

迁移规则：

- 保留用户、库存、装备、市场和交易所数据。
- 保留既有鱼类、鱼饵、装备、商店和卡池 ID。
- 新字段通过顺序迁移添加。
- 空区域映射会自动初始化，已有自定义映射不会被覆盖。

多个 AstrBot 实例共享数据库时，应使用同一版本插件代码。自动钓鱼等后台任务
使用数据库运行锁避免重复执行。

## WebUI

WebUI 默认启用，默认端口为 `7777`：

```text
http://<AstrBot主机>:7777/admin
```

登录密钥由 `webui.secret_key` 指定。不同实例同时运行时必须使用不同端口。

WebUI 可管理：

- 用户及库存
- 钓鱼区域和鱼类映射
- 鱼、鱼竿、饰品和鱼饵
- 道具真实效果及 JSON 参数
- 商店、市场、卡池、称号和交易所
- 冷却、概率上限、税率、出售价格和经济参数

`webui.enabled`、`webui.port`、`webui.secret_key` 仍在 AstrBot 配置页修改，
避免 WebUI 修改自身参数后失去访问。

## 效果术语

- **渔获数量倍率**：`1.30` 表示成功时至少获得 1 条，并有 30% 概率额外
  获得 1 条；`2.00` 表示稳定获得 2 条。
- **高品质触发倍率**：经对数压缩后转换为高品质触发概率。
- **稀有鱼权重加成**：从 1–3 星权重转移到 4–5 星，不提高 6 星以上概率。
- **重量和基础售价倍率**：同时影响本次重量与后续真实出售价值。
- **钓鱼冷却倍率**：`0.75` 表示等待时间减少 25%。

详细定义见 [docs/EFFECT_TERMINOLOGY.md](docs/EFFECT_TERMINOLOGY.md)。

## 数值模型

运行期望值报告：

```bash
python scripts/analyze_balance.py /path/to/fish.db
```

当前基准目标：

- 裸装区域毛回报约 `6.90x–7.01x`
- 当前卡池价格为 `13 / 1000 / 1000 / 20000`，目录价值回报约 `0.75x / 1.20x / 0.65x / 0.59x`
- 常规消耗鱼饵效果大致随成本对数增长
- 高级鱼竿和饰品的通用属性约等于前一级装备精炼 5
- 5 星饰品每小时净收益增幅约 `48%`
- 三个 6 星专精饰品约 `85%–91%`

模型定义见 [docs/BALANCE_MODEL.md](docs/BALANCE_MODEL.md)。

## 开发

```powershell
python -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

主要目录：

```text
core/analytics      期望值与平衡分析
core/config         配置默认值、合并和区域规则
core/database       SQLite 迁移
core/economy        价值计算
core/mechanics      可复用游戏公式
core/repositories   数据持久化
core/services       用例编排
handlers            AstrBot 命令处理
manager             Quart WebUI
tests               单元、迁移和空库启动测试
```
